# Игровая мастерская

Опиши игру словами, и ИИ (Claude) напишет её целиком: HTML, CSS и JS в одном файле. Игра сразу запускается на экране, её можно доработать следующей репликой («сделай быстрее», «добавь бонусы») и скачать как `.html`.

## Как запустить на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него все файлы из этой папки.
2. Открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Сделай push в ветку `main`. Workflow `.github/workflows/main.yml` сам опубликует папку `public/`.
4. Открой ссылку из вкладки **Actions** или **Settings → Pages**, вставь свой API-ключ Anthropic и создавай игры.

## Локально

Открой `public/index.html` в браузере или запусти `python3 -m http.server -d public`.

## Структура

```
public/index.html          приложение целиком
.github/workflows/main.yml публикация на GitHub Pages
LICENSE                    MIT
```

## Про API-ключ

Ключ вводится на странице и хранится в `localStorage` твоего браузера. Он отправляется только на `api.anthropic.com`. Не коммить ключ в репозиторий. Если хочешь дать приложение другим людям без их ключей, поставь между страницей и API свой небольшой сервер-прокси и храни ключ на нём.

Модель задана константой `MODEL` в `public/index.html`.
